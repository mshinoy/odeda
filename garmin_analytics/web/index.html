Gear

Assign gear to any activity retroactively from the activity drawer. Mileage counts activities you have not excluded from stats, and includes each item's initial offset.

Bulk reassign

Apply one item across a filtered date range — the only sane way to add gear to years of imported history. Preview first; it tells you how many activities it would touch.

Default gear for new activities

Applied to activities arriving from a future sync only — never retrospectively, because backfilling years of history with today's shoes would simply be wrong.

Garmin account

Your Garmin password is used once to obtain a token, then discarded. Only the token cache is stored, on the Docker volume, mode 0600. It is never written to the image or to this page.

Garmin refused the login? Sign in with your browser instead

Garmin decides whether a sign-in looks like a browser before it looks at your password, and it often refuses servers outright. This route sidesteps that: your own browser does the sign-in, and hands back a one-time ticket. No password reaches this app.

  1. Open the sign-in page and log in as usual, including any MFA.
  2. The page goes blank — that is expected. The address bar now ends with ?ticket=ST-….
  3. Paste that whole address below. Tickets expire in minutes, so do it promptly.

Sync

A full backfill pulls every activity and every wellness day back to the start of your account. It checkpoints after every activity, so stopping and restarting resumes rather than starting over.

Your edits

Edits live in a separate table keyed on activity and field. A sync rewrites Garmin's values; it has no code path that touches yours.

This deployment

Self-hosted and single-tenant. Garmin Connect has no public API for individuals — ingestion uses an unofficial client and can break without notice. Charts by uPlot (MIT) and maps by Leaflet (BSD-2-Clause), both vendored, no CDN. Map tiles are fetched from the configured tile server when a map is on screen — the one documented external call.
